# Single-Coil Reference
These tracks were recorded on a 1985 Fernandes Custom Shop strat.

## Files

- [./single-coil-bridge-dry.mp3](single-coil-bridge-dry.mp3) - straight off the pickups into audio interface.
- [./single-coil-bridge-reference-fuzz-all-knobs-at-50-percent.mp3](single-coil-bridge-reference-fuzz-all-knobs-at-50-percent.mp3) - the same as the dry track, but run through reference fuzz with all knobs (level, tone, fuzz) at 50%.
- [./single-coil-bridge-reference-fuzz-all-tone-and-fuzz-at-100-percent.mp3](single-coil-bridge-reference-fuzz-all-tone-and-fuzz-at-100-percent.mp3) - the same as dry track, but run through reference fuzz. Tone and fuzz at 100%. Level at 50%.
